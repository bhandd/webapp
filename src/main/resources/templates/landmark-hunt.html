Om projektet

Landmark Hunt är en Android-applikation utvecklad av mig och mina studiekamrater. Konceptet bygger på att användaren använder enhetens platsdata för att hitta, samla och lära sig om landmärken i sin närhet.

Arkitektur och Datahämtning

Appen hanterar asynkrona anrop och platsdata enligt följande struktur:

  • Platsdata: Integration med Androids Location Services för positionering.
  • Primär datakälla: Hämtning av beskrivningar och information via Wikipedia API.
  • Fallback-system: För landmärken som saknar en specifik Wikipedia-artikel anropas automatiskt Wikidata API för att hämta relevant basinformation. Detta säkerställer att användargränssnittet alltid populeras med data.
